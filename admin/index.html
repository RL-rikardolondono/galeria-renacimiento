Configuración inicial (solo una vez)

Para que el panel pueda publicar en la galería, GitHub necesita una llave de acceso. Se pega una sola vez: queda guardada de forma segura en el servidor y nadie tendrá que volver a verla.

  1. Inicie sesión en GitHub y abra esta página.
  2. En Token name escriba: Panel Galería Renacimiento. En Expiration elija No expiration.
  3. En Repository access elija Only select repositories y marque solo galeria-renacimiento.
  4. En Permissions → Repository permissions, ponga Contents en Read and write. Nada más.
  5. Pulse Generate token, copie la llave (empieza por github_pat_) y péguela aquí abajo.

Pedidos

Aquí llegan solos los pedidos que la gente hace en la galería. Cuando Bold confirma el pago, el sistema envía las descargas por correo y pide la impresión de las láminas a Gelato. Las joyas las despacha usted: registre la guía y pulse «Guardar y avisar al cliente».

Precios de la galería

Los precios de cada libro y de cada joya se cambian en su propia pestaña. Aquí están los de las obras de arte, que valen igual para todas. No se cobra IVA. El servidor de pagos siempre cobra lo que diga esta tabla.

Archivos que recibe el cliente

Estos archivos no se ven en la página: quedan guardados en el servidor privado y solo se entregan con un enlace personal después de que Bold confirma el pago. Una obra sin archivo no se puede vender (ni en lámina ni en descarga); un libro sin archivo aparece como «próximamente».

Obras de arte: suba la imagen original (JPG, PNG o TIF) o pegue el enlace del archivo original de Wikimedia Commons (empieza por https://upload.wikimedia.org/). Ese mismo archivo se usa para imprimir las láminas en Gelato. Libros: suba el PDF y el EPUB.
